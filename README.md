# Embedded Linux Lab

Welcome to the **Embedded Linux Lab** – a hands-on, open-source project designed for learning everything from toolchains to board support packages (BSPs), kernel customization, and hardware interfacing using **Yocto**, **Buildroot**, and **CMake**.

---

## 📦 Project Structure

```plaintext
embedded-linux-lab/
├── docs/               # Learning documentation (Markdown)
├── dev/                # Development-related code and tools
│   ├── examples/       # GPIO, UART, SPI, I2C examples
│   ├── scripts/        # Shell utilities for build/setup
│   ├── source/         # Custom libraries and apps
│   └── third-party/
│       ├── yocto/      # Yocto (poky) submodule
│       └── buildroot/  # Buildroot submodule
├── AUTHORS             # Contributors and authors
├── CHANGELOG           # Version history and changes
├── CMakeLists.txt      # Root CMake entry (for dev/examples)
├── CODE_OF_CONDUCT.md  # Community guidelines
├── CONTRIBUTING.md     # Contribution instructions
├── LICENSE             # Open-source license
└── README.md           # This file
```
